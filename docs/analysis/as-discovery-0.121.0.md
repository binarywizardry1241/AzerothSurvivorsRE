## Immutable graph and source drift

The original four query/source records, 93 overlapping historical review records
and stable findings remain available with their original target provenance.
The selected graph's pending states are structural/navigation observations, not
instructions to repeat these completed classifications or revalidate every
historical contract. Missing newest-target correspondence alone does not reopen
implemented behavior or become an eligible source repair.

Final recomposition must use stable current input files. The existing
`--retain-stale-source-reviews` policy retains original source receipts and
captures reviewed/current hash pairs for bounded reviews and forced-pending
native/correspondence leads. It preserves unknown ownership, incomplete/pending
semantics and all strict native target/proof/query/result guards. It does not
manufacture a renewed source review. The derived replay commands preserve that
policy. New commitments create an immutable graph profile. Historical native evidence
and original source receipts retain their actual provenance.

Source/static repairs and classifications described above are distinct from
compilation or execution. No application compilation, compiling test,
client/game/network/server operation, installed save/settings mutation or
original/rebuilt comparison is established by this review. Current reconstructed
execution and full functional/visual parity remain unverified.
