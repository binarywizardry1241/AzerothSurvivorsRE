These are fixture counts, with repeated boundary profiles and shared duration
cases. They are not distinct recovered functions, native coverage percentages
or gameplay parity measurements. Source guards separately inspect live
dispatch, delayed-action, packet, warning, shield/aura, hit and elapsed-area
connections. They do not compile or execute Rust.

The **3,529** profiles above execute original instructions. Twenty-six
additional ranges are decoded and inspected for native stage order, cast/aura/
yell calls, predeath periodic copying and common hit-before-death callback
entry order; they are not extra executed cases. Eleven further context ranges
bind caller inputs and fourteen actual RIP-relative constants to current bytes.
This includes charge speed/minimum/delays, conversion bounds, corpse lifetime,
absolute mask, angle period and the shared half-yard value. Variable fixture
health, power, positions, deadlines and helper outputs remain deliberate inputs.

The [manifest](evidence/0.112.0/raid-lifecycles/manifest.json) records each
suite's actual visited instruction ranges and their current byte hashes.
Ranges already retained by the dispatcher, generic-duration, marker, ward or
guardian-reset owner reference that canonical assembly. A fixed canonical
file list excludes ambient and ignored runtime extracts, and every referred
instruction row is checked against current bytes. Existing Ghidra provenance
for raid inputs/wards/hazards and the shared hit owner is checked by reference.
Overlapping stateful consumer rows reuse the canonical stateful proof. Only previously
unretained visited instructions appear in `selected-native.asm`; no second
dispatcher or duration extract is emitted. Visited ranges also include explicit
seam entrypoints that the fixture intercepts before executing their bodies.
Those entrypoints do not certify the external body.

The source repair follows the current movement and angle contracts. Pull20 uses the
native rounded f32 squared lanes and square root before its ordered `> 30`
rejection. At `dx=0x41efda93`, `dy=0x3f860397`, the native result is
`30.000001907348633`; rounded `hypot` returns `30.0` and previously admitted
the pull. Zero, 30, adjacent values and NaN are retained cases. Pull and
teleport collision shortening now use the same squared-lane order. The native
`fraction >= 1` bypass means a NaN fraction enters shortening and clamps to
zero; teleport now follows that branch. Finally, all six current teleport
payloads hold movement for 0.5 seconds, matching the producer constant and
duration helper; the source previously requested 1 second.

near-origin bypass and knockback fallback use that half-yard boundary; the
source previously used 1 yard. The corrected fixtures now read the owning
constant and include half-yard neighbors and diagonal cone-angle cases.
Shared circle/cone distance, bomb-target distance, knockback distance and pull
arena clamping use actual CRT `hypot` calls. Those source calls remain, with

execute in this suite. Controlled collision fractions and heights exercise
