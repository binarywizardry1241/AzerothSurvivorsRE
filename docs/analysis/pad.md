## Slider policy and exact scope of the source change

Current `14011da10..14011dbc7` admits descriptor indices 0–104 with controls
0–4 and an active Options value vector. It parses the current value, steps and
clamps it, formats through `14012bfd0`, then publishes the ordinary 56-byte
indexed setting command. A positive descriptor step is used directly. A
nonpositive or NaN step falls back to `(maximum - minimum) / 20`.

`Options::device_slider` now implements that fallback instead of rejecting it,
using the existing displayed-value/gamma/write consumer. **All nineteen sliders
in the selected current descriptor table have positive steps.** The fallback
repair restores the native policy; it does not demonstrate a presently affected
default control or change those default steps. Its nonpositive/NaN checks are
explicit synthetic boundaries, rather than invented current settings.
