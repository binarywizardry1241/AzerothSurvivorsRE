Current active loader `14589d550` agrees with the existing source `Save::load` policy. An unavailable active read returns a typed default. A Unicode-trimmed `RSE1:` prefix selects the sealed opener; successful plaintext is passed to the full typed parser. Plaintext compatibility input is parsed directly. Nonempty plaintext first gets a `characters.legacy.txt` copy only when that auxiliary read is unavailable; an existing readable empty copy also prevents replacement. The original untrimmed text is copied.

On sealed-open failure, current helper `14589b9d0` tests `characters.unreadable.1` through `.32`. The first unavailable or byte-identical auxiliary text selects its slot. If all 32 contain different readable content, slot 32 is overwritten. Even an identical existing copy receives the selected write. The loader records its diagnostic and returns a typed default; it does not silently restore an older backup. Auxiliary write errors do not prevent that default. Read/write/path OS behavior remains a separate boundary.
