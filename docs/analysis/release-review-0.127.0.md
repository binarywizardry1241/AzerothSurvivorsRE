## Validation and applicability limits

This review inspects source owners and preserves every supplied item's content
and identity. It does not make a native contract current merely by assigning a
source file or permanent finding. Diagnostic/system selectors locate recovery
work; full-image decoding and native body ownership do not establish semantics.
Every new finding must acquire current contract/producers/consumers proof before
source repair can use the installed EXE as its specification.

No application compilation, compiling tests, game/client/browser/server launch,
network-service operation, save/configuration mutation or controlled
original-versus-rebuilt comparison was performed. Exact current external service
behavior and browser IME behavior require their own authoritative artifacts.
Historical isolated native/Lua/source checks retain their original target and
scope; none is silently promoted to 0.127.0 or to gameplay/visual parity.
