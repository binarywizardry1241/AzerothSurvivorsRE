# Azeroth Survivors discovery

The [discovery graph](coverage/as-discovery.json) links candidates, reviewed
scopes, exact selectors and findings for the registered audit. Use the
[coverage guide](reconstruction-coverage.md) to select the matching census and
unknown queue. The [finding register](../CURRENT-STATE.md#gap-41) owns
outstanding recovery. A decoded range or a diagnostic path can identify where
to look. Establish the native producer, input, output and live source consumer
before registering behavior.

## Feature and resource ownership

Join literals, resource definitions, embedded scripts and native references to
their source consumers. Use the [source frontier](source-frontier.md) for
current ownership and the [data pass](evidence/0.141.0/data-classification/manifest.json)
for candidate evidence. The PaperDoll override illustrates the complete join
from an exact resource and its localized labels to the core loader.

Earlier reviews preserve narrower conclusions. The
[co-op correspondence](coop-correspondence.md) follows transport and
session owners. The [0.120.5 release frontier](evidence/0.120.5/release-policy-frontier.json)
retains callback, authentication, timer and cleanup leads. The
[0.121.0 review input](evidence/0.121.0/as-discovery-reviews.json) records the
selected Heroic and Explosive Orb classifications and their evidence limits.

## Switch and caller correspondence

Applied guarded-table targets establish edges. Follow selector values, caller
state, aliases and layouts separately to determine their meaning. The
[switch context review](switch-context-source-review.md) and
[reference frontier](q41-reference-frontier.md) own the selected proof and
remaining caller questions. Use the [0.139.1 context input](evidence/0.139.1/switch-context-source-review.json)
and [0.140.0 correspondence record](evidence/0.140.0/incremental-correspondence.json)
to trace inherited findings back to their earlier scope.

## Source reconciliation

The [module register](module-contracts.md) connects discovered diagnostics to
reconstructed source and bounded native contracts. Retain separate dispositions
for unknown ownership, a missing implementation and an existing implementation
that needs current-target evidence. Verification remains in the
[verification register](../verification-needed.md).
